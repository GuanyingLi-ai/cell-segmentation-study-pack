## 一、方法概述

### 1.1 StarDist 是什么？

StarDist 是一种 **基于星凸形状参数化的实例分割** 方法：

- **2D**：每个细胞 = 一个中心 + 32 条射线上的边界距离 → **星凸多边形**
- **3D**：每个细胞 = 一个中心 + 多方向射线上的距离 → **星凸多面体**

核心思想：**不逐像素自由勾轮廓**，而是用有限参数描述形状，再光栅化成实例 mask。

### 1.2 与传统方法对比

| 方法 | 思路 | 特点 |
|------|------|------|
| 阈值 + Watershed | 二值化 → 种子 → 区域分裂 | 粘连细胞易过分割/欠分割 |
| 语义/实例分割（逐像素） | 每像素分类或归属 | 形状任意，实例需后处理 |
| **StarDist** | 中心检测 + 星凸形状参数 | 实例明确，适合近凸、可单中心描述的对象 |

## 二、资料包中的复现脚本

### 2.1 两个脚本分别做什么？

| 脚本 | 模型 | 数据 | 规模 |
|------|------|------|------|
| `reproduce_stardist_2d.py` | `2D_paper_dsb2018` | DSB2018 论文 test split | 50 张图，2460 实例 |
| `reproduce_stardist_3d.py` | `3D_demo` | 官方合成 `demo3D.zip` | 3 个体数据，235 实例 |

**共同流程：**

```text
读取 JSON 配置 → 配对 image/mask → 加载预训练模型
→ 逐样本归一化 → predict_instances 推理
→ 保存预测 mask → matching 评价 → 生成 QC 图 → 写入 metrics.json
```

**不做的事：** 重新训练、在 test 上调参、复现论文全部实验表。

### 2.2 关键代码逻辑

```python
# 环境：强制 CPU，便于复现
os.environ.setdefault("CUDA_VISIBLE_DEVICES", "-1")

# 加载官方预训练权重
model = StarDist2D.from_pretrained(cfg["model"])   # 或 StarDist3D

# 百分位归一化
normalized = normalize(image, p_low, p_high, axis=...)

# 核心推理
prediction, details = model.predict_instances(normalized, **predict_kwargs)

# 保存与评价
tifffile.imwrite(masks_dir / name, prediction)
score = matching(truth, prediction, thresh=0.5)
```

### 2.3 配置要点（`configs/*.json`）

| 字段 | 含义 |
|------|------|
| `model` | 预训练模型名 |
| `input_glob` / `label_glob` | 按 **文件名** 配对图像与真值 |
| `normalization_percentiles` | 通常 [1.0, 99.8] |
| `normalization_axes` | 2D: `(0,1)`；3D: `(0,1,2)` |
| `prob_thresh` / `nms_thresh` | `null` 则用模型内置阈值 |
| `iou_thresholds` | 汇总评价 IoU：0.5 / 0.75 / 0.9 |
| `qc_images` | 2D 仅前 N 张出 QC 图（3D 每个 volume 都出图） |

### 2.4 输出产物

```text
outputs/stardist_2d/ 或 stardist_3d/
├── metrics.json      # 环境、阈值、逐样本/汇总指标
├── masks/            # 预测实例 mask（整数 ID，0=背景）
└── figures/          # QC 图（真值绿 / 预测红）
```

**评价指标（StarDist `matching`）：**

- 按 **实例 IoU** 配对预测与真值
- IoU ≥ 阈值 → TP；多余预测 → FP；漏检真值 → FN
- 输出：Precision、Recall、F1、PQ（Panoptic Quality）等
- **不是像素准确率**

## 三、「复现」到底复现了什么？

### 3.1 官方提供 vs 本地计算

| 来源 | 内容 |
|------|------|
| **官方** | 测试图像、真值 mask、预训练权重 |
| **本地** | `predict_instances` 推理结果、metrics、QC 图 |

**结论：** 分割 mask **不是**官方预制图，是本地跑网络得到的；但权重和数据来自官方，且 **没有重新训练**。

### 3.2 复现级别

| 级别 | 含义 | 资料包状态 |
|------|------|-----------|
| **A. 推理复现** | 官方模型 + 官方 test + 本地推理 + 评价 | ✅ 已完成 |
| **B. 论文数字对齐** | 与论文表格逐项一致 | ⚠️ 2D 可参考，3D 不算 |
| **C. 训练复现** | 从头训练、调参、再评估 | ❌ 未做 |

### 3.3 2D vs 3D 的可信度

- **2D**：DSB2018 论文同源真实数据 + 论文模型 → 接近「环境可跑的论文推理基线」（F1@0.5 ≈ 0.93）
- **3D**：官方 **合成 demo** + demo 模型 → 主要验证 **3D 推理链路**，不能代表真实各向异性显微数据（F1@0.5 ≈ 0.998 因数据理想）

### 3.4 为何 IoU=0.5 高、IoU=0.9 低？

- **实例分对**（中心、大致轮廓）相对容易 → 低 IoU 阈值下 F1 仍高
- **边界像素级重合** 很难 → IoU=0.9 时分数骤降

说明 StarDist 擅 **检测与实例分离**，边界精细度是另一层问题。

## 四、推理分割的完整逻辑

### 4.1 总流程

```text
原始图像/体数据
    ↓
百分位归一化
    ↓
U-Net 前向传播
    ├→ prob 图（1 通道）：像不像细胞中心
    └→ dist 图（n 通道）：各方向到边界的距离
    ↓
prob 图：阈值 + 局部极大值 → 候选中心
    ↓
在每个中心读取 n 个 dist → 重建星凸多边形/多面体
    ↓
NMS 去重
    ↓
光栅化 → 实例 mask（0=背景，1,2,3…=实例 ID）
```

### 4.2 第一步：归一化

- 按配置的百分位（如 1–99.8）把强度缩放到约 [0, 1]
- 2D：每张图在空间轴 `(0,1)` 上算
- 3D：整个 volume 在 `(0,1,2)` 上算

目的：消除不同样本间的亮度/对比度差异。

### 4.3 第二步：网络双输出

| 输出 | 通道 | 含义 |
|------|------|------|
| **prob** | 1 | 该处像不像 **细胞中心** |
| **dist** | n（如 32） | 若以此为中心，n 个固定方向到边界的 **距离** |

### 4.4 第三步：确定中心

**推理时没有真值 mask，中心完全由 prob 图自动得到：**

```text
1. prob > prob_thresh（2D≈0.42, 3D≈0.71）
2. 在通过阈值的点中找局部极大值（比邻域都高）
3. 每个峰值 = 一个候选中心
4. NMS：重叠过高的候选只保留 prob 更高的
5. details["points"] = 最终中心坐标
```

**训练时如何教网络：**

- 真值 mask 每个实例用 **距离变换** 找内点（离边界最远 ≈ 几何中心）
- 该点 prob 目标 ≈ 1，背景 ≈ 0
- 从该点向 n 个方向射到 mask 边界 → 监督 dist

### 4.5 第四步：重建形状

在 **每个确定的中心** 上：

1. 读取该点的 n 个 `dist` 值
2. 沿 n 条 **预定义方向** 各走 `dist[i]`
3. 得到 n 个边界点，连接 → **星凸多边形（2D）或多面体（3D）**

**只有中心上的 dist 被使用**；其他像素的 dist 在推理中一般不用于画形。

### 4.6 第五步：NMS

- 两个候选形状 IoU 超过 `nms_thresh`（2D=0.5, 3D=0.3）→ 抑制 prob 较低者
- 保证 **一实例 ≈ 一中心**

### 4.7 第六步：光栅化

- 把所有保留下来的星凸形状「填」进图像/体数据
- `0` = 背景，`1, 2, 3, …` = 实例 ID
- 即脚本中的 `prediction`

## 五、prob 图详解

### 5.1 定义

**prob 图** = 与输入 **同尺寸** 的浮点图，每像素值 ∈ [0, 1]：

```text
prob[y,x] ≈ 1  →  很像某细胞中心附近
prob[y,x] ≈ 0  →  很像背景
中间值         →  边缘、重叠区、不确定
```

### 5.2 prob 图 ≠ 最终 mask

| prob 图 | 最终 prediction |
|---------|-----------------|
| 浮点 0~1 | 整数实例 ID |
| 「像不像中心」 | 「属于哪号细胞」 |
| 中间产物（一般不单独保存） | 脚本写入 `masks/` 的结果 |

### 5.3 直观示意

```text
两个细胞时的 prob 热力（示意）：

  ░░▓▓░░    ░░▓▓░░
  ░▓██▓░    ░▓██▓░     █ = 高 prob（中心）
  ░░▓▓░░    ░░▓▓░░     ░ = 低 prob（背景）
```

每个细胞中间一个 **亮斑（局部峰值）** → 后续取作中心。

### 5.4 与 dist 的分工

```text
prob  →  「选谁当中心」
dist   →  「该中心处细胞有多大、什么形状」
```

## 六、星凸形状限制（核心几何约束）

### 6.1 什么是星凸（star-convex）？

存在内部一点 **C（中心）**，使得：从 C 出发沿 **任意方向** 的射线与形状边界 **最多相交 1 次**。

```text
       边界
        ╱╲
       ╱  ╲
      │ C  │   ← 中心
       ╲  ╱
        ╲╱
```

### 6.2 如何参数化？

**每个细胞 = 中心 C + n 条射线上的距离 [d₀, d₁, …, dₙ₋₁]**

- 2D 常用 **32 条射线**（每 11.25°）
- 3D 为球面上多方向射线 → 多面体

### 6.3 能 / 不能表示什么？

| ✅ 较好 | ❌ 较差 |
|--------|--------|
| 圆、椭圆、不规则但「一团」 | U 形、C 形 |
| 轻度凹陷（射线仍只穿一次） | 带洞、环形 |
| 多数显微细胞 | 分叉、需多中心的对象 |
| | 极细长、强弯曲结构 |

### 6.4 限制如何实现？

**不是后处理过滤，而是表示方式本身：**

- 网络 **只能** 输出 n 个距离 → 轮廓 **只能是** 星凸形
- 没有「自由勾边」的输出通道
- 训练标签也按星凸参数化来监督

### 6.5 为何故意设限？

**优点：**

- 一中心对应一实例，重叠细胞较易拆分
- 参数少，比全图轮廓易训练
- NMS、IoU 匹配自然

**代价：**

- 非星凸结构系统性拟合差
- 中心偏移会导致整细胞形状偏
- 固定射线数对极细结构可能不够

## 七、训练 vs 推理对照

| 环节 | 训练 | 推理（复现脚本） |
|------|------|------------------|
| 中心 | 真值 mask + 距离变换 | prob 图局部峰值 |
| 距离 | 从真值中心射到边界 | 中心处网络预测的 dist |
| 形状 | 监督星凸参数 | 仅用星凸参数重建 |
| 真值 | 使用 label | **不使用** label（仅评价时用） |
| prob | 中心≈1，背景≈0 | 网络自行输出 |

```text
训练：mask → 中心 C_gt + dist_gt → 教网络
推理：图像 → prob + dist → 峰值≈C_pred → 星凸形 → mask
```

## 八、2D 与 3D 异同

| 维度 | 2D | 3D |
|------|----|----|
| 形状 | 星凸多边形 | 星凸多面体 |
| 模型类 | `StarDist2D` | `StarDist3D` |
| 输入 | `(H, W)` | `(Z, Y, X)` |
| NMS | 2D IoU | 3D IoU |
| QC | 1×3（输入/GT/叠加），前 6 张 | 2×3 三正交面，每个 volume |
| 数据性质 | 真实显微（DSB2018） | 合成 demo |
| 典型 F1@0.5 | ~0.93 | ~0.998 |

**底层逻辑相同**：prob 找中心 → dist 画形 → NMS → 光栅化。

## 十、关键术语表

| 术语 | 解释 |
|------|------|
| **prob 图** | 每像素「像细胞中心」的 0~1 分数图 |
| **dist** | n 个方向上从中心到边界的预测距离 |
| **星凸** | 从中心任意方向射线最多穿边界一次 |
| **rays** | 固定角度/方向的射线（如 32-ray） |
| **NMS** | 非极大值抑制，去除重叠候选 |
| **matching** | 按实例 IoU 配对预测与真值 |
| **PQ** | Panoptic Quality，检测与分割质量综合指标 |
| **predict_instances** | StarDist 一键推理 API |

## 十一、自测要点

1. StarDist 的最终 mask 是逐像素分类还是中心+距离参数化？→ **后者**
2. prob 图的作用？→ **找中心**，不是最终分割
3. 形状限制在哪一步？→ **模型输出结构**（只有 n 个 dist），非事后过滤
4. 资料包的「复现」包不包括什么？→ **重新训练**
5. 3D demo 高分能否外推真实数据？→ **不能**，合成数据过于理想
6. 中心推理时从哪来？→ **prob 图局部峰值**，不是真值 mask
